- Ручной запуск сцен с общим временем перехода 0–30 с. Переход и плавное снятие
  предыдущей сцены выполняет MA2; автоматическая цепочка сцен не создаётся.
- Глобальное затемнение сохраняет исходный Grand Master в журнале и возвращает
  его после контрольного чтения; сцены и Programmer сохраняются.
- Концертный экран: сцены рядом с постоянным планом, выбор приборов в отдельном
  окне, интерфейс для компьютера и планшета.
- DMX readback с TTL 6 с, восстановление профилей и честные неизвестные значения.
- Относительные Pan/Tilt, синхронизация Patch/групп, восстановление после потери
  связи и отмена старых действий нескольких клиентов.
- Исправлен перенос прибора 23→31 при одновременном появлении нового №23.
  Неоднозначные сопоставления подтверждаются явно; ссылки групп, позиционных
  пресетов и выделения переносятся одновременно, новый прибор не наследует данные.
- MA2-группа после Blackout или смены контекста не отправляет старую команду.
- Запуск сцены снимает только прежние запуски панели в текущем плане/шоу;
  посторонние сцены каталога не получают массовые Off.
- Пакетная архитектура, Windows x64 комплект, updater, миграции и recovery journals.
- Дополнительно: ссылки приборов в метаданных сцен, отмена Store Group после Blackout и единый runtime-ID для совместимости с Windows v3.2.5.
- После transport drain старые команды отменяются до записи; Undo не снимает защиту неизвестной записи сцены. Исправлен PID запуска из Windows venv.
