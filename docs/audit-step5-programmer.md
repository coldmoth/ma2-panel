# Аудит шаг 5: Remote/UserProfile, Programmer и Highlight

## Факты кода

**scene_go с ClearAll** ([commands.py](../ma2panel/commands.py#L273))
Каждый запуск сцены начинается с `ClearAll`, затем `Go Executor` без fade либо `Goto Cue 1 Executor` с fade. Комментарий: значения в Programmer остаются поверх сцены. Команда отправляется без проверки содержимого Programmer.

**release_highlight: Off и восстановление** ([bridge.py](../bridge.py#L304))
Снятие подсветки отправляет `Off Fixture` для зоны, затем восстанавливает записанные значения dim/color/pan/tilt/zoom/focus/strobe через `At`. Не проверяет содержимое Programmer перед Off или восстановлением. Фактический эффект Off требует проверки в зале.

**highlight_action: проверки editing и allow_highlight** ([bridge.py](../bridge.py#L343))
Подсветка требует `editing=True` и `allow_highlight=True`. Первое включение записывает `restore` из `state["shown"]` (значения приборов), фильтрация атрибутов по `state["sent"]`. Затем отправляет `At 0` для старых приборов и `At <level>` для выбранного.

## Неизвестное

- **Профили пользователей**: пользователь Remote имеет полные права; неизвестны конфигурация профиля Remote и профиль текущего оператора, совпадают ли они.
- **Содержимое Programmer**: на момент ClearAll/Off/At неизвестно, пуст ли Programmer оператора, содержит ли временные значения от других операций или изменения другого пульта/устройства.
- **Семантика ClearAll и Off**: не подтверждено на MA2, затрагивают ли команды только текущий профиль Remote или весь Programmer/выбор оператора, сохраняются ли значения Programmer после выхода Remote или обрыва.

## Безопасный протокол зала

1. **Пассивный сбор**: записать через UI MA2 версию ПО, активных пользователей, профили Remote и оператора, содержимое Programmer оператора перед тестом. Если профиль общий — остановиться без команд.
2. **Проверка Programmer**: оператор проверяет и фиксирует непустое состояние; непустой Programmer не очищается протоколом без исключений.
3. **Активные тесты**: только отдельное разрешение; согласованный тестовый сеанс с копией шоу. Копия не сохраняет временный Programmer/выход.
4. **Запреты**: не использовать Store/Delete/User/Off диапазона, не запускать произвольные сцены, не очищать непустой Programmer в рамках этого протокола.

## Критерии будущего патча

- Чужой Programmer и выбор оператора сохраняются; для глобальных сцен/команд изоляция от чужих значений требует проверки.
- Сохранить существующее ограничение редактором; уточнить с владельцем, достаточно ли его для подготовки.
- Выход/обрыв Remote: без повторной отправки ClearAll/Off при переподключении.
- Семантика очистки (ClearAll scope, Off vs. Clear) согласуется с оператором до изменений.
