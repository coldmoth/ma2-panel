# Установка, данные и проверка работоспособности

Этот документ описывает текущий порядок установки и восстановления. Точные
параметры onPC — [SETUP](SETUP.md), работа со светом — [USAGE](USAGE.md).
Mock и автоматические тесты не подтверждают поведение физических приборов.

## Установка и подключение

1. Распакуйте **полный Windows x64 ZIP** в отдельный каталог. Сохраните старую
   установку целиком. Не распаковывайте полный комплект поверх пользовательских
   файлов: его шаблоны предназначены для новой установки.
2. Запустите grandMA2 onPC 3.9.60 с нужным шоу. Включите Telnet и настройте
   отдельного пользователя по SETUP. Не меняйте Patch или Programmer ради диагностики.
3. Запустите внешний `start.bat`; в мастере укажите подключение и сохраните пароль
   на этом ПК. Примените настройки перезапуском. LAN включайте только при необходимости.
4. Сверьте имя шоу на onPC и привязку плана. Загрузите оборудование и прочитайте
   группы штатными действиями. В диагностике проверьте готовность, карты типов,
   Patch и DMX. Неизвестное состояние не является выключенным светом.

Диагностика готовности автоматически вычисляется после старта и обновляется
пассивно. Откройте «Диагностика» на основном ПК через localhost: причины
`Ошибка`, `Неизвестно` и `Ограничено` сопровождаются безопасным следующим действием.
Проверка не включает полный доступ и не посылает пробных световых команд.
`selfcheck.bat` читает этот же пассивный отчёт и доступность страниц; код 0 означает,
что все полученные проверки PASS, а не что свет измерен на приборах.

## Где данные и как их сохранить

Legacy-пути сохранены: пользовательские config/settings/secret.env, shows,
highlight, rdm-search, диагностика и backups находятся в `program` установленного
комплекта. `.updates` — recovery, `previous` — предыдущая программа для отката.
**Удаление каталога установки удаляет и эти данные.** Перед переустановкой,
сменой пути или компьютера остановите мост и сохраните данные за пределами установки.
Не удаляйте старую копию до проверки новой.
При аварийном завершении самого restore может остаться `.data-transfer.lock`
и частично заполненное назначение. Не запускайте его как готовую установку:
сохраните обе папки и исходный приватный ZIP, повторите restore в ещё одну новую
пустую установку. Инструмент не выдаёт незавершённый перенос за успешную копию.

Из `program` выполните в командной строке, заменив пути своими:

```bat
python\python.exe data_transfer.py backup "C:\ma2-panel\program" "D:\Private\ma2-data.zip" --confirm-stopped
python\python.exe data_transfer.py preview "D:\Private\ma2-data.zip"
python\python.exe data_transfer.py restore "D:\Private\ma2-data.zip" "C:\ma2-new\program" --confirm-stopped --confirm
```

В исходниках используйте `uv run python data_transfer.py ...`. Архив приватный:
он включает **пароль и пользовательские данные**. Не отправляйте его как диагностику.
Каталог назначения архива должен уже существовать. Копия включает backups и
завершённые recovery/rollback-снимки, проверяется по SHA256/размерам, источник
не удаляется. Символические ссылки и конфликтующие данные отклоняются.
Подтверждение остановки обязательно; инструмент не останавливает рабочую MA2.

Для восстановления нужна новая установка без конфликтующих пользовательских
данных. Полный комплект уже содержит config/settings-шаблоны: после остановки
переместите **только эти заведомо новые шаблоны** в отдельную папку, затем выполните
restore. Не удаляйте неизвестные или рабочие config/settings для обхода конфликта.
Незавершённое recovery, неизвестный журнал или активная транзакция блокируют backup:
сначала выполните штатный запуск/recovery и проверьте результат. Повреждённый RDM-журнал
сохраняется побайтово; его перенос не подтверждает RDM Off.

Перенос кода `previous` не меняет runtime новой установки. После смены пути/портов
заново выполните firewall-open.bat при необходимости LAN. Сверьте настройки экспорта
MA2: прежние абсолютные пути могут требовать явного исправления в мастере.

## Обновление, RC и откат

Обновление через настройки, USB или LAN использует совместимый update ZIP,
сохраняет пользовательские данные и готовит `previous`. Полный ZIP не заменяет
совместимое обновление. При сбое запустите start.bat для recovery; для штатного
отката используйте rollback.bat и следуйте [USB-инструкции](update-usb.txt).
Не смешивайте Python/lib/runtime-файлы из разных комплектов.

RC/test — отдельный prerelease. Stable-updater отвергает draft и prerelease;
установка RC выполняется явно на отдельной тестовой копии. Stable требует
обязательных автоматических результатов, совпадения SHA/ZIP, отдельного review,
данных V3 и аппаратной приёмки именно кандидата. См. [QUALITY-GATES](QUALITY-GATES.md).

## Как собрать данные за одно посещение

На localhost откройте диагностику → «Собрать данные для тестирования».
Просмотрите список файлов, SHA256, размер и недостающие сведения, затем сохраните
**тот же снимок** локально. Предварительный просмотр действителен пять минут;
новая сборка заменяет предыдущий снимок. Ничего не отправляется во внешнюю сеть.

Архив содержит структуру приборов/локальных групп/сцен, разрешённые технические
карты, обезличенные копии доступных XML и статусы готовности. Имена заменены,
логины, сетевые адреса ПК, пути, пароли и сырые логи не включаются. XML отмечены
как исторические и преобразованные; неподдерживаемые поля не копируются.
Это не резервная копия и не побайтовый оригинал XML.

Если нужного свежего XML нет на диске, пассивный сборщик его не создаст:
оператору нужно один раз отдельно выполнить разрешённое чтение Fixture/Patch,
FixtureType и групп и подтвердить SHOWFILE/VERSION. Экспорт — команда на MA2;
она не запускается кнопкой пассивного сбора автоматически.

Обычный «диагностический пакет» с исходными логами — другой архив; он может
содержать персональную информацию. Проверяйте его перед передачей.

## Что остаётся проверить в зале

Раз в неделю — короткий чек-лист 10–15 минут в [QUALITY-GATES](QUALITY-GATES.md):
сверить шоу/вход/readback, одну RGB/Fresnel-группу, две головы, две тестовые сцены,
Blackout и возврат. Рабочие Cue не перезаписывать. Дополнительная приёмка
[hall-test-plan §12–13](hall-test-plan.md) остаётся обязательной для соответствующих изменений.
