# Этап 2 — передача на независимый review (2026-11-10)

База: d80babb, codex/stage1-scenes. Изменения: codex/stage2-state.
Это **передача**, независимый review не проводился. Помощники не разрешены;
субагенты/Clodex/платные вызовы не использовались. Merge/push/release исключены.

## Проверить прежде интеграции

1. `read_dmx`, `expire_dmx`, `dmx_diagnostics`: nonce/span/0..255, TTL от начала
   чтения, отдельные retry для блоков, повтор не раньше 30 с, ограничение трёх
   отказов на блок/контекст, пауза ≥100 мс. Старый DMX не становится actual.
2. `identify_show`, `on_state`, `blocked`: нет управления в recovering;
   свежий login ListVar, совпадение шоу, refresh Patch после reconnect.
   Неоднозначность/ошибка не разрешает старые действия, очереди очищаются.
3. `merge_fixtures`, `commit_import`: перестановки IDs без перезаписи источников,
   явный выбор неоднозначности, все ссылки групп, сохранение ручных свойств,
   ошибка диска до инвалидирования карт, старые версии dmx_map_saved.
4. `ma2_action`: список/состав групп, complete/empty/partial/error/stale,
   сохранение label, проверка шоу через свежий ListVar перед импортом/выбором,
   поколение/план/шоу после await и до сохранения/Group n.
5. Shutter: только поддерживаемый 8-bit диапазон; неизвестные/пересекающиеся
   интервалы и strobe не выдаются за белый/открытый выход. Нет универсального
   декодера XML/CMY/сложных instances или реальных физических координат.
6. Ранее готовые scene runtime, native crossfade, Grand Master Blackout и safety
   команды не переписывались. Recovery gate применяется и к ним: проверить
   совместимость после реального reconnect, особенно при запрещённом экспорте.

## Ограничения для onPC и площадки

- Официальные команды и runtime-предпосылки разведены в ma2-command-evidence.md.
  Точная сигнатура getdmx должна сверяться с plugin_1.lua/ListPluginLibrary
  конкретной сборки 3.9. onPC на этом этапе не запускался.
- Подтвердить свежими XML структуру Instance/Patch, Shutter и состав Groups;
  неизвестный формат должен давать отказ/unknown. Валидный семантически
  укороченный XML без независимого списка IDs неотличим от удаления.
  Пустой нераспознанный экспорт не доказывает пустоту Patch.
- Проверить физические Pan/Tilt, единицы/диапазоны разных профилей, инверсии,
  одновременную правку оператором, Programmer/Executor и реальный DMX.
  Mock моделирует поведение только для проверки цепочки/логики.
- Между Export и Group n другой оператор может изменить состав; атомарного
  снимка между сессиями нет. Нужна договорённость о параллельной работе.
- Для повторного подключения с Patch требуется allow_fixture_read; при запрете
  показана причина блокировки, оператор явно включает чтение/обновляет приборы.
