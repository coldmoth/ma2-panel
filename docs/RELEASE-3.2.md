# ma2-panel 3.2.0 — Pre-release

2026-11-06. **Приёмка с настоящим grandMA2 ещё не выполнена.**
Версия предназначена для контролируемых испытаний с grandMA2 onPC.

## Что нового и UX/UI

Последний завершённый «Сценический атлас»: графитовая палитра, навигация слева,
крупный план и инспектор, независимые рабочие области на планшете и компактный
телефонный вид. Поиск по ID/имени/типу, быстрый выбор групп, подписи, zoom/pan/lasso,
личная видимость инструментов. Это рабочая панель поверх настоящего Python-моста.
Старые концепции, прототипы Opus и отдельный demo-адаптер не поставляются.

Сохранены сцены и Executor, выбор/мультивыбор, Dimmer/Color/Pan/Tilt, джойстик и
независимые ползунки, ±1°, относительное управление несколькими головами, пресеты и
группы, зал, патч, настройки, Programmer, Highlight, Blackout, reconnect и запись
настроек. Опасные операции доступны только при существующих разрешениях моста.

## Исправления

Устойчивое восстановление выбора после reconnect с проверкой свежего config и ACK;
исправлен доступ к Zoom/Focus у приборов без Pan/Tilt. Устранены перекрытия джойстика,
растянутый план и наложения меток. Отдельная обратная связь различает ожидание,
ошибку, неизвестный результат и ответ без ошибки, не выдавая их за физическую проверку.
Автоматического воспроизведения старых команд нет. Протокол MA2 и safety guards
в рамках подготовки релиза не изменялись.

## Требования и установка

Windows **10/11 x64**, браузер Chrome/Edge, grandMA2 onPC **3.9** с Telnet Remote,
права записи в папку установки. ZIP использует embedded **CPython 3.12.10 x64** и
зависимости из `uv.lock`, без настройки Python пользователем. Исходники: Python
**3.12+ x64**, Git и uv; Node нужен только для тестов. Связь с onPC — локальная или
доверенная LAN. Интернет нужен для скачивания/первой установки из исходников.

[Скачать релиз](https://github.com/coldmoth/ma2-panel/releases/tag/v3.2.0).
`ma2-panel-win.zip` и SHA256 публикуются только после настоящей Windows-сборки и
проверки запуска на runner. Распакуйте всю папку в новое место и откройте внешний
`start.bat`. Не копируйте один батник отдельно от `program`.
[Краткая установка и первый сеанс](ONPC-HALL-TEST-3.2.md), [полная настройка](SETUP.md).
Если ZIP отсутствует, используйте описанную в инструкции установку из исходников;
автономный Windows-комплект в таком случае не подтверждён.

Новая установка имеет пустой план, `test`, пустые разрешения, loopback HTTP и
намеренно ненастроенный `ma2-unconfigured.invalid`. В мастере
http://localhost:8080/setup.html явно задайте адрес onPC (127.0.0.1 на том же ПК),
Telnet-порт (обычно 30000), пользователя отдельного профиля и пароль. Сохраните и
перезапустите мост. Панель: http://127.0.0.1:8080, простой режим: порт 8090.
`--mock` и `program/start-mock.bat` — отдельная явно обозначенная имитация.
Реальный запуск их не использует. Личных настроек, секретов и шоу в поставке нет.

На новом ноутбуке используйте полную установку в отдельную папку. Существующие
данные перед переносом сохраните целиком; публичные шаблоны их не заменяют.
Runtime обновления привязан к Python и SHA256 lockfile. Смена номера проекта меняет
этот хеш даже без обновления зависимостей: обновление ZIP на прежний runtime не
поддерживается. Браузерное обновление для этой первой установки не требуется.

## Проверки и ограничения

Статус конкретного прогона и артефактов публикуется в GitHub Release.
Локальные pytest/Node, HTTP/WebSocket и Chromium/WebKit проверяют программную часть
без настоящего оборудования. Windows runner проверяет Windows x64 и shipped runtime;
это не ручная проверка на целевом ноутбуке и не MA2-приёмка.

Известен отказ диагностического теста браузерного updater в Windows venv: PID
launcher отличается от PID отвечающего Python, строгая health-проверка отвергает
новый процесс. Проверка безопасности PID не ослаблена. Перед залом устанавливайте
полный комплект отдельно; обновление во время управления не используйте.

Форматы ответов MA2, истинный Running/Off, независимость UserProfile Programmer,
диапазоны Pan/Tilt/точность ±1°, относительные шаги, типы CMY/Shutter, RDM, переходы,
реальный общий Blackout и запись/загрузка шоу остаются на аппаратную приёмку.
Playwright WebKit не подтверждает iPad, физический touch и Windows grandMA2.
Независимый review новых релизных изменений в этой сессии не проводился.

Первый тест: подтверждённый вход → один разрешённый Fixture ID → безопасное небольшое
изменение под контролем оператора → сравнение журнала, onPC и физического результата.
[Пошаговый сценарий](ONPC-HALL-TEST-3.2.md). Не начинайте с Blackout или всего света.

Исходники — [GNU GPL v3](../LICENSE), GPL-3.0-only. SHA256 проверяет целостность;
это не независимая цифровая подпись издателя. Сборка не подписана Authenticode.
