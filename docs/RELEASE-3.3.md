# ma2-panel 3.3.0

## Изменения

- Ручной запуск сцен с общим временем перехода 0–30 с. Переход и плавное снятие
  предыдущей сцены выполняет MA2; автоматическая цепочка сцен не создаётся.
- Глобальное затемнение сохраняет исходный Grand Master в журнале и возвращает
  его после контрольного чтения; сцены и Programmer сохраняются.
- Концертный экран: сцены рядом с постоянным планом, выбор приборов в отдельном
  окне, интерфейс для компьютера и планшета.
- DMX readback с TTL 6 с, восстановление профилей и честные неизвестные значения.
- Относительные Pan/Tilt, синхронизация Patch/групп, восстановление после потери
  связи и отмена старых действий нескольких клиентов.
- Исправлен перенос прибора 23→31 при одновременном появлении нового №23.
  Неоднозначные сопоставления подтверждаются явно; ссылки групп, позиционных
  пресетов выделения и метаданных сцен переносятся одновременно, новый прибор не наследует данные.
- MA2-группа после Blackout или смены контекста не отправляет старую команду.
- Запуск сцены снимает только прежние запуски панели в текущем плане/шоу;
  посторонние сцены каталога не получают массовые Off.
- Runtime-ID сохраняет совместимость с Windows v3.2.5 при разных окончаниях строк Git checkout.
- Неизвестная запись сцены остаётся заблокированной после Undo конфига; старые команды отменяются также после ожидания Telnet.
- Исправлена проверка PID после обновления из Windows venv без ослабления health-проверок.
- Пакетная архитектура, Windows x64 комплект, updater, миграции и recovery journals.

## Обновление

С v3.2.5 — штатный updater и `ma2-panel-update.zip` при совпадающем runtime.
С v3.2.0–v3.2.4 — внешний комплект `ma2-panel-update-usb.zip`: распаковать отдельно,
остановить приложение и указать установленную папку `program`.
Для нового компьютера — `ma2-panel-win.zip`, Python включён.
Пользовательские настройки, пароль, шоу, backups и журналы восстановления сохраняются.
Не удалять `previous/` и `.updates/` до проверки новой версии.

## Границы проверки

Программные проверки и mock не доказывают поведение физических приборов.
Исторический прогон onPC 3.9.63.11 проверял команды/пустые Cue, Grand и нулевой
DMX без подключённого света; он не является приёмкой новой пакетной интеграции.
В этой сессии реальная MA2 не подключалась. На целевой onPC 3.9.60 необходимо
проверить кривые crossfade, HTP/LTP/Programmer, прерывание перехода, сложные
FixtureType и восстановление после обрыва связи. Матрица: [приёмка](hardware-acceptance.md)
и [зал, разделы 12–13](hall-test-plan.md).

После перезапуска процесса либо смены плана/шоу панель не угадывает владельца
уже работающих сцен. Перед первым запуском оператор проверяет текущий свет
на MA2; чужие playback автоматически не снимаются. Свежий Off-readback исключает
лишнее снятие, устаревшее чтение не отменяет возможный запуск с неизвестным ответом.
Readback является наблюдением, а не гарантией отсутствия внешнего действия
между чтением и командой. Полная аппаратная приёмка остаётся отдельным шагом.
