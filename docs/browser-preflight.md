# Browser preflight перед залом

Для обмена файлами шоу есть отдельный изолированный сценарий:
`uv run python scripts/show_files_smoke.py --output /tmp/ma2-show-files-browser`.
Он запускает Chromium/WebKit, симулирует запись/загрузку MA2 только во временных
каталогах, проверяет upload/отмену/подтверждение/download, сохранение, reload,
повреждённый файл, offline/recovery и ширину 390 px. Артефакты: PNG, скачанные
mock `.show.gz` и mock.log. Это не настоящие шоу и не проверка совместимости MA2.

Проверка настоящими движками Chromium и WebKit через Playwright, в mock.
Не подтверждает Safari на iPad, Android Chrome, сенсорный драйвер планшета,
настоящий grandMA2 или физическое движение приборов.

## Повторяемый запуск

Из корня проекта, Python ≥3.12, Node ≥20:

```sh
uv sync --locked
npm ci --prefix scripts/browser_smoke --ignore-scripts
node scripts/browser_smoke/node_modules/playwright/cli.js install chromium webkit
uv run --no-sync python scripts/browser_smoke.py --output /tmp/ma2-browser-preflight
```

На Linux для установки системных библиотек браузеров вместо `install` использовать
`install --with-deps chromium webkit`. Это зависимости разработки; production Python
и панель не получают новых зависимостей. Версия Playwright зафиксирована в lockfile.
`--node /absolute/path/to/node` задаёт другой Node executable.
Если Playwright уже есть в bundled runtime Codex, можно пропустить npm-установку
и передать каталог его `node_modules` через `NODE_PATH` (пути узнать через
`load_workspace_dependencies`). Браузерные binaries ставятся CLI той же версии.

Каталог `--output` содержит `results.json`, stdout/stderr mock в `mock.log` и PNG:
диалог, джойстик, абсолютное положение, простой режим и состояние обрыва каждого движка; при ошибке —
также снимок `*-failure.png`. Старые файлы в каталоге не удаляются: для отдельного
отчёта выбирать новый каталог. Успех — код 0 и шесть строк `PASS`; отсутствие
движка или ошибка проверки завершают команду ненулевым кодом, без пропуска теста.

## Что проверяется

- Chromium и WebKit, landscape viewport 1024×768, touch-capable context.
- Полный и простой HTTP-порты одного mock-моста, mock действительно подключён.
- Касания кнопок всех разделов, запуск тестовой сцены, открытие/закрытие диалога
  редактирования; отмена подтверждения blackout простого режима ничего не отправляет.
- Pan/Tilt: настоящий pointer drag мышью отправляет обе оси; после отпускания
  отправка прекращается. Реальное перетаскивание абсолютных ползунков отправляет
  `aim` отдельно для Pan и Tilt. Пад, шаги и оба ползунка помещаются в viewport.
- Обрыв browser↔bridge: offline плюс закрытие настоящего WS; управление недоступно,
  активный жест отменяется. После reconnect без отпускания старого жеста ни одно
  действие не воспроизводится автоматически. Это не тест обрыва Telnet MA2.
- Мастер подключения: 1024×768 и 390×844, сохранение LAN без подмены действующего
  состояния, недоступность при offline и восстановление; снимки каждого движка.
- Нет горизонтального переполнения документа во всех разделах и простом режиме;
  диалог помещается в viewport; нет необработанных JavaScript `pageerror`.

Жест Pan/Tilt здесь проверяется мышиным PointerEvent браузерного движка.
Касания кнопок идут через Playwright touchscreen. Реальный touch drag, pointercancel,
потерю фокуса, поведение при сворачивании и смене ориентации нужно дополнительно
проверить руками на целевых планшетах перед залом. Снимки позволяют осмотреть
компоновку, но не заменяют ручную оценку читаемости и удобства.

В CI добавлено отдельное задание `browser-preflight` в
[ci.yml](../.github/workflows/ci.yml): оба движка в Ubuntu, PNG/JSON/log сохраняются
на три дня при успешном или неуспешном запуске. Существующие pytest, DOM и Windows
smoke остаются отдельными заданиями. Локальный результат не подтверждает запуск CI.

## Изоляция

Launcher копирует только корневые `*.py`, `static/` и читает публичные
`config.example.json`/`settings.example.json`. Создаёт синтетические голову,
группу и сцену. Настройки, export, шоу, backups, diag, лог и PID принадлежат
временной копии. Рабочие config/settings, `.env`, `secret.env` и шоу не читаются.
Дочерний процесс всегда `--mock`, bind только `127.0.0.1`, два свободных порта.
Пароль MA2 и переключатель реального формата mock не наследуются. Завершение
останавливает только созданный PID и удаляет временную копию, в том числе при
ошибке браузера. `--output` выбирать вне рабочих данных.
