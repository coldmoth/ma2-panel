# ma2-panel: управление и интерфейс после установки — 2026-11-13

База: `730e820dd67d00620def5ceaee052aaf60858774` (`codex/quality-audit-fixes`).
Кандидат: `codex/field-regression-fixes`; точный коммит — HEAD этой ветки.
Отдельное managed worktree; исходные деревья не менялись. Выпуск не публиковался.

## 1. Конкретные причины потери управления

Подтверждено воспроизведением на коде базы и падающими регрессиями:

1. Реальный Export Fixture V2 содержит Fixture/Patch/адреса/число каналов,
   но не имена атрибутов. Видимость приборов и соединение поэтому не доказывают
   наличие сведений о Dimmer/RGB. UI обоснованно отказывает до FixtureType.
2. `read_types` после единственного неудачного экспорта помещал тип в
   `types_tried`: дальнейшие фоновые попытки в этом соединении пропускались.
   Временный отказ оставлял работающий прибор без доступных регуляторов.
3. Отказ Lua завершал `poll_dmx`, единственный фоновый путь получения типов.
   При `dmx_seconds=0` такого пути вообще не было. После reconnect карта
   становилась stale, но восстановить её автоматически было некому.
4. Успешный разбор типа отмечался до commit. Если сохранение отменялось из-за
   смены контекста/редактирования, профиль не попадал в конфиг, но кеш запрещал
   повторное чтение. Предварительное изменение метаданных также могло менять
   revision без завершённой записи и мешать сохранению сцены.
5. `parse_fixture_type` не сохранял подтверждённые PAN/TILT. Голова без
   атрибутов в Patch и без узнаваемого имени оставалась без движения.

Связь этих дефектов с единственным конкретным сеансом площадки нельзя установить
однозначно без диагностики того сеанса. Неизвестные реальные FixtureType не
восстановлены догадками. Отдельный экспорт V3 не требуется: владелец подтвердил
эквивалентность конфигурации V2 и V3; существующий V2 используется как полевой набор.

## 2. Что исправлено

- Ошибки чтения типа допускают повтор через 30 с; ручное получение запускает
  чтение сразу. Повторяются только чтения типов.
- Получение типов работает без DMX-readback; отклонённая Lua больше не
  отправляется до перезапуска, но получение FixtureType продолжает работать.
- Карта и отметка успешного чтения применяются вместе, после проверок контекста.
  Отменённое чтение можно повторить. Фон откладывается для активного редактора
  и действующего предложения свободного места сцены.
- PAN+TILT из текущего подтверждённого профиля учитываются в UI и мосте.
  Stale/unsupported карта не подтверждает движение.
- В «Свете» постоянно видны Группы/Приборы/План, состав обеих разновидностей групп,
  поиск и «Снять выбор». Последнее очищает сессию моста без команд света.
- План занимает большую долю ширины; сохраняет пропорции, масштаб/перемещение,
  выбор нескольких приборов. Планшет не получает горизонтальной прокрутки.
- Добавлены настройки локального отображения Dimmer/RGB/Pan-Tilt/Zoom/Focus/Strobe.
  Учитываются и отдельные карточки, и оптика экрана движения. Ключ `ma2.interface`
  совместим с прежними локальными предпочтениями; разрешения MA2 не меняются.
- В выбранной базе плана в «Сценах» уже не было. Это сохранено и проверяется;
  запуск/выключение/запись/Fade/Blackout остаются в общем браузерном наборе.
- Обновлены spec, история, changelog и генерируемый индекс. Версия 3.3.1 остаётся
  неопубликованным кандидатом; новые зависимости не добавлялись.

## 3. Пользовательские сценарии

Новый field-start: пустые fixtures/groups/ma2groups/dmx_map → реальное действие UI
получения → Patch без Attribute → отдельные экспорты FixtureType → доступные
регуляторы → независимый вывод консоли. Синтетический тип называется Profile A,
поэтому движение проверяется без угадывания головы по названию.

| Сценарий | Подтверждение |
| --- | --- |
| Чистая установка, подключение, получение приборов/FixtureType | field-start, оба движка |
| Отдельный прибор, яркость и RGB, нет воздействия на соседний | независимый mock output |
| Пустые группы → чтение/импорт MA2 → выбор одним действием | состав/selection/output |
| Создание группы панели, множественный выбор | UI и сохранённый config |
| Pan/Tilt подтверждённой головы | output обеих осей двух приборов |
| Неподдерживаемый цвет | недоступные регуляторы и объяснение |
| Повторный импорт, reconnect и перезапуск процесса | карты, группы, команды/output |
| Снять выбор | output неизменен; команд света нет |
| Strobe отдельно; Zoom/Focus в движении; все шесть инструментов | UI, reload, сохранность карты |
| Создание зала/расстановка/выбор на плане | действия редактора и backend selection |
| Нет плана в сценах; запись, Go/Off, Fade, Blackout/возврат | общий synthetic browser suite |
| Настройки/группы/план после обновления и rollback | release_lifecycle в clean-SHA runner |

## 4. Что подтверждено только симуляцией

Синтетические FixtureType/составы групп и independent mock не являются реальными
профилями V2/V3. Значения Dimmer/RGB/Pan/Tilt, сцены и Blackout проверены в этом
oracle, а не физическим светом. Источник simulation не объявляется MA2-readback.
Полевой набор V2 проверяет настоящий XML Patch и 24 прибора, начиная с пустой
панели; полного реального FixtureType/membership в этом наборе нет.

## 5. Что требуется без симуляции

Отдельный независимый review патча, Windows CI нетронутого ZIP и приёмка MA2
по hall-test-plan §12–13 остаются обязательными перед выпуском. Проверить
реальные экспорты типов, права/каталоги onPC 3.9.60, составы групп, адресатов и
физический свет, движение в безопасном диапазоне, Programmer/Highlight,
сцены/Fade/Blackout и сохранность рабочего шоу. Настоящий пульт не подключался.
