## Согласованные правила

Каждый запрос имеет ID; ответ связан с запросом; reconnect не повторяет действия. Результаты: completed, partial, failed, unknown. Ответ MA2 не доказывает физический свет. Общий план защищён версией: устаревшее сохранение отклоняется.
Владелец выбрал абсолютные горизонтальные Pan/Tilt вместо регуляторов скорости. Существующий джойстик, зеркальность и инверсии сохраняются. Неизвестные и разные значения явно обозначаются; отображение само ничего не отправляет.
DMX: только нужные интервалы, ограниченная работа за цикл и уступка ручным действиям. Существующий MA2 Lua-синтаксис сохраняется.

## Приёмка перед выездом

В тестовый комплект входит GPL-3.0-only (выбор владельца 2026-11-03); кандидат версии 3.1.0rc1 не является принятым выпуском. Новый интерфейс отправляет request_id и config_revision; старые клиенты сохраняют прежний формат ответа, но устаревшие записи также отклоняются.

### Первый сеанс в зале

1. Сохранить действующую установку и шоу; поставить тестовый комплект рядом, начать с mock. Проверить Windows запуск/два порта/firewall, отправку обезличенной диагностики и обновление/откат на копии.
2. Без изменений света записать версию MA2, пользователей и профили Remote/оператора. Если профили общие — активные проверки Programmer отложить до согласованной изоляции.
3. Получить Executor/статусы по hall §12b/12c и XML используемых типов; не отправлять широкие Off/Store/ClearAll в рабочее шоу.
4. С оператором на отдельном тестовом шоу пройти гашение §12d, сцены §12e, Programmer, запись Output и частичные сбои. Заранее определить ручное восстановление.
5. На настоящих головах измерить задержку ручного управления при DMX-опросе, проверить диапазоны абсолютных Pan/Tilt и существующие инверсии. На Android/iPad — реальные touch/cancel/сворачивание/reconnect.
6. Сохранить обезличенные результаты, только после них реализовать/уточнить MA2-зависимые изменения. Ожидается продолжение разработки после первого сеанса; mock не закрывает пункты3/5/6/7/11/27.

Публикация GitHub, запуск удалённого CI и Windows-приёмка не подтверждаются локальной сборкой. Исходную историю репозитория не публиковать: только очищенный снимок по существующим правилам.

Проверены прекращение жеста при обрыве и отсутствие replay при reconnect.

Независимое review после исправлений не нашло P1/P2. Исправлены выявленные ошибки баннера операций, присвоения чужих изменений результату запроса и некорректных полей a. Подтверждены RED→GREEN регрессиями; полный набор повторён после исправлений. Единственное предупреждение pytest — существующее предупреждение Starlette/httpx.

Для первого перехода с3.0 использовать полный комплект рядом со старой установкой и перенос данных по инструкции: полный lock hash изменён, обновление из прежнего runtime требует отдельной приёмки.

Манифесты, SHA256 update ZIP, совпадение71 программного файла full/update, шаблоны config/settings и отсутствие рабочих данных/паролей в архивах проверены отдельно.
