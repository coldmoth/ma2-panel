## 4. Найденные и исправленные ошибки этого аудита

1. **Разъехавшиеся этапы.** Совмещены наследники общей базы; исходное dirty
   дерево сохранено. UI и сервер теперь проверяются вместе.
2. **Локальный Fade не менял серверное время сцены.** Настройка проходит
   revision/очередь, приходит другим клиентам и используется быстрыми значениями.
3. **Отсутствующий server blackout_epoch.** Старые сообщения, pending/fades,
   извлечённые intent, in-flight строки и Undo больше не переживают затемнение.
   Blackout отменяет очередь вместо отправки старых slider значений перед ним.
4. **Unknown Grand выглядел как idle.** Оба интерфейса показывают причину,
   не предлагают автоматическое повторное переключение.
5. **Цвет после отмены жеста переставал работать.** Swatch и RGB-слайдеры
   проверяют поколение своего контрола; новый жест работает, поздний старый нет.
6. **Lua probe не соответствовал настоящему объектному дереву.** Playback
   опции читаются из List Executor; CMD — из Cue Part по точному имени;
   учитывается отсутствующий начальный slot Sequence. Нет safe defaults для nil.
7. **Copy открывал интерактивный выбор метода.** Backup и commit получили
   документированный CueOnly; commit сохраняет ограниченный Overwrite.
   Guard стал строже, NoConfirm не добавлялся. Mock воспроизводит диалог.
8. **Второй greeting prompt ломал login.** Он дочитывается в прежнем timeout,
   без повтора login; пользователь по-прежнему подтверждается свежим ListVar.
9. **Lua ACK опережал новый nonce.** Только завершённые ListVar со старым
   маркером дочитываются ограниченно. Свежий unknown/ошибка транспорта — отказ.
10. **Grand ACK опережал изменение уровня.** После одной записи допускаются
    ограниченные новые замеры; успех требует наблюдения target, иначе журнал/unknown.
11. **Selfcheck под cp1252 терял отчёт.** CLI настраивает UTF-8 до сообщений;
    регрессия проверяет настоящий subprocess с принудительным cp1252.
12. **Windows QA падал при освобождении DLL.** Только cleanup своей временной
    папки повторяется максимум 5 с; body assertion и постоянная блокировка остаются ошибкой.
13. **Backup пропускал новые recovery journals.** Добавлены blackout.json и точные имена
    scene-write-<page>.<executor>.json. Повреждённое содержимое сохраняется побайтово;
    регрессия проверяет backup→restore, перенос, update→rollback; та же проверка
    добавлена в доставленный Windows runtime.

Каждое исправление поведения сначала подтверждено падением теста либо реальным
onPC, затем адресным зелёным прогоном. Старые тесты синхронизированы с принятым
контрактом: намеренная отмена pending перед Grand не очищает Programmer MA2;
общий Fade требует серверного подтверждения; тестовые tickets берутся из
настоящего action_ticket. Проверки сохранности/ошибок не удалялись.
