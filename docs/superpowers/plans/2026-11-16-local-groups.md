# Локальные группы LUMA

Основание: подробное задание пользователя от 2026-11-16. Продолжение в текущей
ветке, без помощников, установки зависимостей и изменений световых команд.

1. Расширить существующий group_save: необязательный id обновляет локальную
   группу, отсутствующий создаёт; пустой состав допустим; ID без дубликатов.
   Сохранять неизвестные поля, валидировать цвет/иконку, запрещать группы с n.
   Использовать существующие revision/action_lock/атомарную запись/broadcast.
   Сначала регрессионные тесты CRUD, отказов и отсутствия команд пульту.
2. Добавить FixturesWorkspace и GroupEditor в стиле существующей консоли.
   Навигация: все/типы/локальные/MA2. Состав в основной области, принадлежность
   на карточках. Основные действия видимы, оформление и удаление в меню.
   Редактор состава с поиском и отметками; добавить выбранные в существующую
   либо новую группу. Shift сохраняет текущую модель выбора.
3. Передавать revision снимка редактирования, не перетирать чужое изменение;
   ошибка оставляет черновик. Блокировать повтор до ACK. Выбор группы хранить
   по ID; после удаления убрать метку и выделение, после редактирования
   повторный выбор в Зале использует новый состав. MA2 только просмотр/выбор.
4. Адресные Python/Node, production build и Chromium/WebKit: пользовательский
   сценарий, пустые группы, конфликт/ошибка/задержка, отмена, reload и сохранение
   на диске, отсутствие изменений расстановки и световых команд при CRUD.
   Снимки desktop/tablet, отчёт, контракт/история/индекс/TASK_STATE, локальный коммит.

Фокус проверки: устаревшая revision; удаление выбранной группы; пустой состав;
пересекающиеся группы; сохранность неизвестных полей/координат. Независимого
review нет по ограничению на помощников, перед общей интеграцией требуется.
