# ma2-panel 3.1.0

Выпуск от 2026-11-03. Изменения относительно [3.0.0](RELEASE-3.0.md) опубликованы в [CHANGELOG.md](../CHANGELOG.md).

## Что изменилось

- Независимые абсолютные Pan/Tilt, чтение DMX порциями и защита параллельных правок.
- Проверяемые обновления через браузер и точный откат программы.
- Миграции планов, подтверждение XML-импорта и обмен файлами `.show.gz` через браузер.
- Управляемый поиск RDM с проверкой выключения.
- Очередь обезличенной диагностики через HTTPS без GitHub-ключей на площадке.
- Переносной Windows-комплект и мастер подключения с офлайн QR.
- GPL-3.0-only и автоматические проверки исходников, mock и браузерных движков.

## Установка и файлы релиза

Для новой установки Windows x64 скачайте `ma2-panel-win.zip`, распакуйте всю папку и запустите внешний `ma2-panel/start.bat`. Программа находится в `program/`; мастер подключения поможет настроить локальную onPC. Проверка без пульта — `program/start-mock.bat`.

`ma2-panel-update-usb.zip` содержит USB-обновление; `ma2-panel-update.zip` и его `.sha256` предназначены для совместимой установленной среды. Контрольные суммы файлов — в `SHA256SUMS.txt`.

**Переход с 3.0:** полный `uv.lock` изменился, поэтому обновление программы поверх старого runtime будет отклонено. Распакуйте полный комплект 3.1 в отдельный каталог, сохраните резервную копию старой установки и перенесите локальные данные по [SETUP.md](SETUP.md). Проверка переноса на целевой Windows ещё требуется; не заменяйте рабочую установку до неё.

## Ограничения

Публикация не означает приёмку на оборудовании. Готовность к работе в зале пока не подтверждена. Windows-комплект собирается на macOS; запуск комплектного Python на Windows, реальные касания планшетов и команды MA2 требуют отдельных проверок. Политика сцен и настоящее общее гашение остаются открытыми вопросами зала.

## До проверки в зале

- Собрать полный Windows x64-комплект и USB-обновление из окончательного
  состояния исходников, проверить состав, манифест и установку на Windows
  с комплектным Python; затем проверить обновление и сохранность локальных данных.
- На целевых Android-планшете и iPad проверить landscape, реальное касание и
  перетаскивание, отмену жеста, потерю связи, сворачивание и возврат приложения.
- На настоящем grandMA2 подтвердить Pan/Tilt и исходящие команды, чтение DMX,
  переходы сцен, форматы ответов и остальные открытые пункты
  [плана проверки в зале](hall-test-plan.md), особенно разделов 12–13.

Переход с установленного 3.0 требует отдельной проверки: совместимость runtime
проверяется по SHA256 всего `uv.lock`, который изменился вместе с номером проекта. Выпуск не
объявляет старый Windows-комплект совместимым с новым USB/LAN-архивом. Нужен
проверенный способ перехода или отдельная полная установка с сохранением данных.

До этих проверок не считать выпуск готовым к залу. Не отправлять команды
на рабочий пульт ради проверки без отдельного явного запроса владельца.

## Состав и лицензия

Полная панель и простой режим сохраняются; настройка описана в
[SETUP.md](SETUP.md), работа — в [USAGE.md](USAGE.md).
Локальные пароли, планы шоу, настройки площадки и диагностика в пакет не входят.

Исходники проекта — **GPL-3.0-only**: [полный текст GPL версии 3](../LICENSE).
Более поздняя версия лицензии автоматически не разрешена. Корневой LICENSE
исходников копируется в `docs/LICENSE.txt` единого программного payload и
включается в его манифест. Этот payload используется полной Windows-сборкой,
USB- и LAN-обновлением. Лицензии сторонних библиотек остаются их собственными.
