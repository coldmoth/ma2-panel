# ma2-panel 3.1.1 — тестовый выпуск

Пакет накопленных исправлений и инфраструктуры доставки. Не является приёмкой
программы для концертной эксплуатации; аппаратные задачи grandMA2 остаются открыты.

- Исправления надёжности сцен, DMX/RDM, отмены устаревших действий и сохранности данных.
- Проверка официальных GitHub Releases, release notes, подтверждение выбранной версии,
  ограниченные HTTPS redirects, проверки SHA256/manifest/runtime/платформы/места.
- Сохранены USB/LAN, транзакционный установщик, recovery и rollback.
- Общий Windows x64 упаковщик с embedded Python 3.12.10 и зависимостями по lockfile;
  воспроизводимые Windows/USB/update ZIP с SHA256 и build-inputs.json.
- CI для Python/Node, Chromium/WebKit и доставляемого Windows-комплекта, только --mock.

## Установка и совместимость

Использовать изолированный тестовый Windows x64 ПК и полный `ma2-panel-win.zip`.
Внутри — Python; системный Python/uv на целевом ПК не требуются.
Перед переносом сохранить пользовательские настройки, секреты, шоу, планы,
backups, `.updates` и `rdm-search.json` с pending/target. Не снимать неизвестный
pending и не повторять физическую RDM-операцию ради установки.

Идентичность runtime пока использует SHA256 полного uv.lock, включая версию проекта.
В 3.1.1 lock отличается от 3.1.0: программный update ZIP будет отклонён старой
установкой как несовместимый. Нужен полный комплект с контролируемым переносом
пользовательских данных. Это ограничение существующего runtime gate; обхода нет.

Обновления Python/lib требуют полного комплекта. USB/LAN не удалены.
GitHub prerelease не предлагается обычным stable-updater и автоматически не устанавливается.
SHA256 подтверждает целостность; независимой криптографической подписью не является.

## Ограничения приёмки

Не завершены независимый review updater, испытания на чистой Windows VM,
UAC/ACL/locked files/прерывание питания и аппаратная приёмка grandMA2.
GitHub Actions/mock не доказывают физическое управление светом.
Проверки конкретного выпуска и SHA опубликованы вместе с GitHub Release.
