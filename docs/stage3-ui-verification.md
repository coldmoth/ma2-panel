## Результат

- Сцены рядом с постоянным рабочим планом и параметрами; на портретном планшете
  список сцен ограничен по высоте. План доступен без открытия окна выбора.
- Один Fade 0–30 с для сцен и быстрых значений; перетаскивание немедленное.
  Состояние сцены — чтение MA2; переход — зарегистрированная операция моста.
- Прямая кнопка сохранения, существующий поиск slot/token, отдельное подтверждение
  перезаписи; технический адрес спрятан в деталях. Unknown/partial/error не закрывают
  диалог, имя остаётся, результат виден внутри него.
- Показания и статусы обновляются адресно. При жесте сохраняется thumb, фактическое
  значение видно отдельно. Ввод текста не мешает обновлению readback/блокировок;
  blur применяет отложенную структуру. Черновик зала переживает внешний config.
- Поздний отказ старого выбора не сбрасывает новый. Все каналы отменяются при смене
  цели; прерванный жест не возобновляет отправку после Blackout/обрыва/скрытия вкладки.
- Непрочитанные возможности подписаны; неподтверждённые регуляторы скрыты.
  Источник цвета доступен сразу, HSV Value — «Яркость цвета».
- Подготовка разделена на подключение/синхронизацию, приборы/Patch, план, группы,
  сцены, шоу, историю, диагностику. Сводка не выдумывает отсутствующее число изменений.
