# ma2-panel 3.0.0

Первая публичная версия планшетной панели для grandMA2 onPC 3.9: сцены для персонала, управление светом и подготовка площадки для оператора.

## В составе

- Полная панель на 8080 и простой режим со сценами на 8090.
- Яркость, цвет, Pan/Tilt, пресеты, схема зала, группы и локальные планы шоу.
- Защита исходящих команд, разрешения записи и опасных операций, история и диагностика.
- Исходники и шаблоны настроек; Windows x64-комплект с Python; USB-обновление.

## Установка

Для новой Windows-установки скачайте `ma2-panel-win.zip` и распакуйте всю папку. Начните с `start-mock.bat`, затем настройте пользователя MA2 и локальный `secret.env`. Для существующего комплекта предназначен `ma2-panel-update-usb.zip`.

Для исходников: [SETUP.md](SETUP.md). Инструкция: [USAGE.md](USAGE.md). Изменения: [CHANGELOG.md](../CHANGELOG.md).

## Ограничения

Релиз предназначен для доверенной локальной сети, без публичного доступа. Стартовый план пустой; права на приборы и сцены задаются с оператором. Пароли и рабочие данные площадки в комплект не входят.

Автоматические проверки и mock не заменяют проверку на MA2. В этом выпуске реальные команды на пульт не отправлялись. Переходы сцен, разбор отдельных типов приборов, RDM и другие неподтверждённые сценарии проверяются по [плану зала](hall-test-plan.md). Windows-комплект собран на macOS; его запуск на целевой Windows требует отдельной проверки.

Внутренние названия v1–v4 и схема config version 4 сохранены; публичный номер релиза — 3.0.0. Публичная история Git начинается с очищенного снимка; история разработки кратко отражена в changelog.
