# Шаг 6: общее гашение — проект для проверки

Дата: 2026-11-02. **Локальное проектирование выполнено; механизм не согласован и не испытан.** Код и контракт не изменены. Выполнил Codex по новому запросу владельца; платных вызовов Sonnet не было: каталог вернул HTTP 503.

## Цель и текущая граница

Решение владельца: погасить весь свет текущего шоу, включая источники оператора вне списка панели. Следующий выбор сцены возвращает свет без отдельной кнопки выхода; прежние источники не должны снова засветиться. Работа оператора сохраняется.

Сейчас [bridge.py](../bridge.py), `lines_for`, выключает сцены конфига и отправляет `At 0` приборам плана, кроме служебных/пропавших. В ограниченных режимах охват дополнительно сужают `allowed_scenes` и `allowed_fixtures`. Это не общее гашение. `commands.build` сам формирует только Off сцен; добавление At выполняет мост. `execute` отправляет строки последовательно: ошибка посередине не отменяет уже выполненное. Подтверждение Telnet не доказывает темноту.

## Варианты и рекомендация

| Вариант | Польза | Ограничение |
|---|---|---|
| Расширить Off/At | Можно явно перечислить управляемые источники | Нужен полный состав шоу; At меняет Programmer; источники вне перечня остаются. Не подходит как универсальное решение |
| Штатный Blackout On/Off | Отдельная маска выхода, явное включение/выключение | Не устраняет старые источники; снятие маски может вернуть их свет. Не покрывает все приборы |
| Согласованный механизм конкретного шоу | Учитывает исключения и порядок восстановления | Требует настройки оператором и повторной приёмки при изменении шоу; макрос сам по себе не доказывает охват |

**Предложение:** сначала испытать штатный `Blackout On` как маску, отдельно проверить подготовку новой сцены под маской и только затем её снятие. Не внедрять простую пару On → Off вокруг существующего запуска: старые Executor и Programmer могут вернуться.

По [руководству MA2 3.9, Blackout](https://help.malighting.com/grandMA2/en/help/key_keyword_blackout.html), команда подавляет dimmer; `React to Master = Off` исключает прибор. Команда без On/Off переключает состояние, поэтому для будущего кода непригодна. [Park](https://help.malighting.com/grandMA2/en/help/key_keyword_park.html) фиксирует значения DMX; его взаимодействие с маской здесь не подтверждено. Приборы без dimmer, Park, DMX-вмешательства и внешние источники требуют отдельной проверки. Если маска не покрывает нужный свет, оператор проектирует механизм шоу; обещание общего гашения до этого недостоверно. Автоматически менять React to Master, снимать Park или обнулять весь DMX не предлагается.

## Будущая операция и границы управления

Предлагаемый порядок: отменить несовместимые таймеры/fade и ожидающие значения; включить маску; при следующем выборе под маской выключить старые источники согласованным способом, подготовить Cue 1, затем снять маску. Точный синтаксис, полнота перечня Executor и обращение с Programmer ещё не определены: зависимости — [шаг 3](audit-step3-executors.md), [шаг 5](audit-step5-programmer.md), будущий шаг 7. Сохранять содержимое чужого Programmer обязательно; его влияние на выход при этом может потребовать отдельного согласования.

`action_lock` упорядочивает только клиентов моста, а не оператора MA2. Для пяти клиентов нужна общая версия операции/шоу/соединения; устаревшее завершение не должно снимать более новое гашение. Если оператор сам включил Blackout, панель не должна автоматически его снимать. Правило владения маской и способ чтения её состояния требуется подтвердить; локальный флаг этого не доказывает.

При частичном сбое/unknown дальнейшие стадии останавливаются; маска автоматически не снимается, компенсации и повторы при reconnect запрещены. После reconnect — чтение, неизвестность показывается явно. После ошибки окончательный свет и состояние маски проверяет оператор. Оба UI должны различать отправку, известное состояние маски и неизвестный результат, не обещать физическую темноту по ответу команды.

В будущем `safety.make_guard` должен отдельно проверять точные разрешённые команды и полномочие общего гашения **до** разрешения режима full/extra regex. Нельзя обходить ограниченный режим ради глобального воздействия. Согласовать доступ учителей на 8090 и поведение при отсутствии разрешения; тихое частичное гашение недопустимо. Сейчас эти правила не реализованы.

## Проверка в зале и критерии

Только отдельный согласованный сеанс с оператором и копией тестового шоу. Сначала записать версию MA2, профили, исходные Programmer/выбор, B.O., masters, Park, активные Executor и источники DMX. Копия шоу не сохраняет временный Programmer/выход; заранее определить ручное восстановление оператором. Не отправлять команды в рабочее шоу по этому документу.

| Источник в тестовом шоу | Проверить |
|---|---|
| Сцена панели и Executor оператора вне config, другой страницы, с несколькими Cue | Гашение, запуск новой Cue 1 без возврата старого света |
| Programmer Remote и оператора, Highlight, работающий эффект | Темнота; содержимое/выбор чужого Programmer сохранены |
| React to Master On/Off, разные типы, прибор без dimmer | Физический охват; исключение означает непрохождение общей приёмки |
| Park dimmer/DMX, прямой DMX, внешний источник/merge, если используется | Охват фиксируется отдельно; не снимать ограничения автоматически |
| Fade/таймер, пять клиентов, действие оператора, обрыв на каждой стадии | Нет позднего включения, автоповтора и снятия чужого Blackout |

Для каждого случая фиксировать ожидаемое/фактическое: физически погасло; новая сцена вернула только нужный свет без отдельного выхода; оператор смог продолжить управление. На время восстановления исключить несогласованные действия. При непредвиденном свете, изменении чужого Programmer, неизвестном состоянии или потере управления — остановить тест, восстановление только оператором по заранее записанному плану. Не рассчитывать на Oops как универсальный откат.

Будущие регрессии: сначала RED для возврата старого источника, запоздалого снятия маски, частичного сбоя и обхода safety; затем реализация. Дополнительно — отмена ожидающих слайдеров/fade, смена шоу/соединения, пять клиентов, чужая маска, reconnect без записи, ошибки в обоих UI. Mock проверяет порядок и запреты; физический результат — только зал.
