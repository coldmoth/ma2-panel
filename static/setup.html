Подключение MA2

Первичная подготовка на основном компьютере. grandMA2 onPC нужно открыть самостоятельно.

Проверяю мост…

1. Подготовьте grandMA2

Для существующего шоу сохраните свою работу в MA2. Мастер не загружает другое шоу и не включает свет.

  1. Откройте Setup → User & Profiles Setup под пользователем с правами администратора.
  2. Если отдельной учётной записи панели ещё нет, создайте отдельный User Profile, затем User и назначьте ему этот профиль. Используйте то же имя пользователя и пароль в форме ниже. Для управления и записи нужен подходящий уровень прав, например Full.
  3. Проверьте, что оператор onPC использует другой профиль: общий профиль может объединить выборку и Programmer.
  4. В Setup → Console → Global Settings → Telnet установите Login Enabled.

Если пользователь и Telnet уже настроены, используйте их. Достаточно выполнить подготовку один раз для нужного шоу; после смены шоу проверьте её снова.

Официальная инструкция MA2

Пользователи и профили · Telnet. Ссылки требуют интернета; шаги выше доступны без него.

2. Подключите панель

Используйте отдельный роутер света. Сохранение меняет только настройки панели; они применяются после перезапуска моста.

Действующее подключение

Проверяю…

Подтверждение входа не доказывает раздельность Programmer и правильность DMX. Доступные операции и режим защиты задаются в настройках.

3. Откройте панель на планшете

Подключите компьютер и планшет к одному роутеру света. Отсканируйте QR или введите адрес в браузере планшета. Интернет не нужен.

Если планшет не подключается

Включите доступ по локальной сети выше и перезапустите мост. На Windows выберите для сети роутера профиль «Частная сеть». В папке program запустите firewall-open.bat от имени администратора. Роутер должен разрешать связь устройств между собой. При нескольких адресах попробуйте адрес Wi-Fi роутера света.

Адреса обновляются каждые 5 секунд. Если в шоу нет приборов и сцен, панель останется пустой: их нужно настроить в MA2, затем прочитать на «Площадке».
